# Imagens do site

Use estes nomes para substituir os espaços já preparados no layout:

- `brand/logo-horizontal.svg` — logo horizontal principal
- `brand/favicon.svg` — símbolo 1:1 para favicon
- `brand/og-cover.jpg` — imagem de compartilhamento (1200x630)
- `hero/hero-agriculture.webp` — imagem principal da home (recomendado 1600x1200)
- `about/responsavel-tecnico.webp` — foto vertical do responsável técnico (recomendado 1200x1500)
- `blog/<slug-do-artigo>.webp` — capas do blog

Prefira WebP para fotografias e SVG para marca e elementos vetoriais.
